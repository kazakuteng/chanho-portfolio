# Backend × AI Developer Portfolio

Vue 3와 Vite로 만든 반응형 취업 포트폴리오입니다. SSAFY Python 비전공 트랙, 현재 공통 프로젝트, 실제 사용자가 있는 Django 운영 서비스 경험을 중심으로 구성했습니다.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 표시되는 로컬 주소를 열면 됩니다.

## 내 정보로 바꾸기

`src/data/portfolio.js`만 열어 이름, 이메일, GitHub, 소개, 프로젝트 내용을 수정하세요. 확인되지 않은 정보는 의도적으로 placeholder로 남겨 두었습니다.

## 검증

```bash
npm run verify
```

이 명령은 코드 규칙 검사, 콘텐츠 테스트, 배포용 빌드를 차례로 수행합니다.

## 하네스 엔지니어링

이 프로젝트는 Codex가 반복해서 안정적으로 작업할 수 있도록 요구사항, 작업 규칙, 체크리스트, 자동 검증을 저장소 안에 둡니다. 자세한 흐름은 `docs/workflow.md`에 있습니다.
